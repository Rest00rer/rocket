# План реализации

Каждый этап заканчивается списком изменённых файлов, выполненных проверок и
оставшихся рисков. Следующий этап начинается после проверки предыдущего.

## 1. Модель и миграции

- SQLAlchemy-модели из `docs/architecture.md`;
- Alembic migration;
- повторяемый seed;
- ограничения БД и тест seed.

## 2. Чтение данных

- товары, склады, inventory summary;
- история с фильтрами;
- backend-тесты контрактов.

## 3. Склады и приход

- создание, переименование, архивирование;
- приход;
- проверка поведения архивного склада.

## 4. Перемещения

- draft, dispatch, receive;
- транзакции и row locking;
- повторное подтверждение.

## 5. FBS и FBO

- reserve/cancel/ship;
- FBO ship/receive;
- нехватка на выбранном ФФ и альтернативы.

## 6. Идемпотентность и конкурентность

- сохранение результата команды;
- конфликт payload;
- параллельные списания;
- интеграционные тесты PostgreSQL.

## 7. Интерфейс

- таблица остатков;
- формы действий;
- путь товара и история;
- loading/error/empty/retry;
- сценарий нехватки и архивный склад.

## 8. Финальный аудит

- сверка каждого пункта `docs/specification.md`;
- чистый запуск по README;
- тесты и линтеры;
- README с решениями, компромиссами и использованием AI;
- сценарий видео на 3–5 минут.
